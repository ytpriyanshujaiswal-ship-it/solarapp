Pushpendra Power Solar - Website (HTML + Tailwind CSS, no React)

Kholne ke liye: index.html par double-click karein, ya poora folder kisi bhi hosting par upload karein.

Pages: index, about, services, calculator, contact
Files: css/style.css (compiled Tailwind), js/main.js (menu, estimator, form)

Design badalne ke liye (optional):
  npm install
  npm run build     (HTML mein Tailwind classes badalne ke baad CSS dobara banata hai)
